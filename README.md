# 🎮 Number Guessing Game

A fun number guessing game where the player tries to guess a randomly 
generated number within a set range. Gives hints after each guess.

## ✨ Features

- Random number generated each round
- Hints after every guess — "too high" or "too low"
- Tracks number of attempts
- Play again without refreshing the page
- Fully responsive layout

## 🏃 How to Run

No install needed — just open `index.html` in any browser.

```bash

npx serve .
```
